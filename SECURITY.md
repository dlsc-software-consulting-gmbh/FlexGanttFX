# Security Policy

## Supported versions

Security fixes are provided for the latest released FlexGanttFX line. Please use the newest available release before reporting an issue when possible.

## Reporting a vulnerability

Please do not open a public GitHub issue for a security vulnerability.

Preferred reporting channel:

- Use GitHub's private security advisory flow via the repository **Security** tab, then **Report a vulnerability**.

Fallback:

- Email Dirk Lemmermann at <dlemmermann@gmail.com>.

Please include:

- Affected FlexGanttFX version and modules
- Java and JavaFX versions
- Operating system
- Steps to reproduce or a minimal proof of concept
- Impact and any known workarounds

## What to expect

DLSC aims to acknowledge vulnerability reports within a few business days. As a small vendor, exact fix timelines depend on severity, complexity, and release scheduling.

Please give DLSC reasonable time to investigate and prepare a fix before public disclosure. We appreciate coordinated disclosure and will credit reporters when appropriate and requested.
