# Archived documentation

This directory contains the **previous** version of the FlexGanttFX website and
documentation. It is kept for reference only and is **no longer maintained**.

Parts of it are outdated. In particular it still describes the license-key based
activation that older versions of FlexGanttFX required. FlexGanttFX no longer uses
license keys — the library can be built and used without any licensing setup.

The current documentation lives in [`../docs`](../docs) and is published at
<https://www.flexganttfx.com>.
