Java 11+

Release Archives — Java 11+

Binary ZIP archives for Java 11 and higher. Add the JAR files in the libs folder to your classpath, plus the third-party JARs in the ext folder.

11.12.8 January 17th, 2024

JAR files are no longer OSGI bundles.

Download
11.12.7 November 2nd, 2023

Fixes issues related to the rendering of links.

Download
11.12.6 January 30th, 2023

Fixes a single issue where key events were dropped while dragging an activity inside the Gantt chart.

Download
11.12.5 March 30th, 2022

Fixed various rendering issues where vertical lines were not aligned properly (grid lines, 'now' line), chart layout scale fixes, scrollbar behaviour fixes.

Download
11.12.4 April 21, 2021

Enhanced the scrollbar behaviour for "fixed horizon" scrolling. The end date of the horizon will now remain on the right edge of the viewport.

Download
11.12.3 April 9th, 2021

Added support for a fixed horizon scrollbar. Added a flag for turning on/off auto-hiding the scrollbars. Fixed the drawing of grid lines when displaying hour granularity with a step rate larger than 1.

Download
11.12.0 May 14th, 2020

Replaced custom mouse cursors with standard system cursors. Row resizing via new row headers on right-hand side. Removed dateline scrolling events. Enhanced RadarView's rendering performance.

Download
11.11.0 May 2020

Replaced icon PNG files with Ikonli font icons. Added show / hide links support (incl. toolbar button). Added row headers for right-hand side. Redraws now batched and using pulse listener for increased performance.

Download
11.10.0 Performance March 2020

Replaced LinksPane with LinksCanvas. Links are now drawn via Canvas API. Replaced observable list of activity links with an IntervalTree for faster lookup. Customizable link renderers. Fixed CSS issue in Dateline layout code.

Download
11.9.1 October 24th, 2020

Various bug fixes and enhancements.

Download
Java 8

Release Archives — Java 8

Binary ZIP archives for Java 8 (uses the JavaFX version bundled with the JDK). Add the JAR files in libs and ext folders to your classpath.

Replaced custom mouse cursors with standard system cursors. Row resizing via new row headers on right-hand side. Removed dateline scrolling events. Enhanced RadarView's rendering performance.

Download
8.10.0 March 2020

Replaced LinksPane with LinksCanvas. Links are now drawn via Canvas API. Replaced observable list of activity links with an IntervalTree for faster lookup. Customizable link renderers. Fixed CSS issue in Dateline layout code.

Download
8.9.0 April 8th, 2019

Added support for a "frozen" row inside the timeline. Various bug fixes. Moved property support / property sheets into "extras" module.
