安装

FlexGanttFX 12.4.0 已在 Maven Central 发布。使用 Maven 或 Gradle 添加 view 依赖。如需可选的辅助控件，请同时添加 extras。

Maven

<dependency>
    <groupId>com.flexganttfx</groupId>
    <artifactId>view</artifactId>
    <version>12.4.0</version>
</dependency>

<!-- 可选的辅助控件 -->
<dependency>
    <groupId>com.flexganttfx</groupId>
    <artifactId>extras</artifactId>
    <version>12.4.0</version>
</dependency>

Gradle

implementation "com.flexganttfx:view:12.4.0"
implementation "com.flexganttfx:extras:12.4.0" // 可选

许可

FlexGanttFX 采用双重许可。如果你自己的应用以相同许可开源，则可以免费在 GNU Affero 通用公共许可证 v3 下使用它。 对于专有、闭源或 SaaS 应用，则需要商业许可证。无需安装许可证密钥 — 详情请参阅许可页面。

创建应用程序类

以下代码清单展示了启动 Gantt 图表用户界面所需的最基本设置。


import javafx.application.Application;
import javafx.scene.Scene;
import javafx.stage.Stage;

import com.flexganttfx.view.GanttChart;

public class MyFirstGanttChart extends Application {

    @Override
    public void start(Stage stage) throws Exception {

        // <- Our Gantt chart
        GanttChart<?> gantt = new GanttChart<>();

        Scene scene = new Scene(gantt);

        stage.setScene(scene);
        stage.centerOnScreen();
        stage.sizeToScene();
        stage.show();   
    }

    public static void main(String[] args) {
        Application.launch(args);
    }
}
