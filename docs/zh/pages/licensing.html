简单透明的许可

选择适合你需求的许可证 — 覆盖个人开发、企业级生产部署和学术研究。

开发许可证

30 天试用期结束后即需要此许可证。它允许继续开发，但不能用于交付或生产环境 — 这些场景需要运行时许可证。

  • 包含 30 天免费试用
  • 开发期间可访问完整 API
  • 基础支持与错误修复
  • 不得用于生产 / 交付
申请许可证

企业运行时许可证

发布、交付或销售任何基于 FlexGanttFX 构建的应用程序都需要此许可证 — 无论是内部部署还是面向客户部署。

  • 不限数量的生产部署
  • 内部应用与面向客户的应用
  • 可选年度维护计划
  • 高级支持选项
  • 维护期内免费版本更新
