探索由 JPro 提供支持的交互式 FlexGanttFX Showcase 演示 — 无需安装。直接在浏览器中体验 FlexGanttFX 的完整功能范围。

FlexGanttFX Showcase

FlexGanttFX Showcase 是一个综合性演示应用，展示 FlexGanttFX 内置的完整功能和能力。无需安装即可试用所有控件、布局、渲染器和定制选项。

什么是 JPro？

上述在线演示背后的技术 — 可直接在浏览器中运行任何 JavaFX 应用，无需插件或安装。

JPro 是由 SANDEC GmbH 开发的商业产品，充当 JavaFX 应用的服务器端渲染桥接层。JPro 不在最终用户机器上运行 JavaFX 应用，而是在服务器上运行它，并使用标准 Web 技术（HTML5、WebSockets 和 SVG/Canvas）将渲染输出流式传输到任何现代浏览器。

从用户角度看，应用完全具备交互性 — 鼠标点击、键盘输入、拖放和滚动的行为都与原生桌面应用完全一致。从开发者角度看也没有变化：你只需编写并维护一套 JavaFX 代码库，JPro 负责 Web 部署。

FlexGanttFX 可与 JPro 无缝配合，因为它是完全基于 JavaFX Canvas 和 Scene Graph API 构建的纯 JavaFX 控件。不需要特殊移植或适配 — 只要能在桌面运行，就能通过 JPro 在浏览器中运行。

服务器端渲染

JavaFX 应用运行在你的服务器上。JPro 渲染每一帧，并通过 WebSocket 连接实时流式传输到浏览器。

零代码改动

你现有的 JavaFX/FlexGanttFX 代码库可原样工作。JPro 以库的形式集成 — 无需重写，也无需维护单独的 Web 前端。

任意设备，任意浏览器

可在台式机、笔记本、平板和智能手机上运行 — 支持 Chrome、Firefox、Safari 和 Edge。客户端不需要 Java 运行时或插件。

数据保留在服务器上

由于应用在服务器端运行，敏感数据永远不会离开你的基础设施。非常适合有严格数据治理要求的企业部署。

多用户与多会话

JPro 可在同一服务器上处理多个并发用户会话，每个会话都有隔离的应用实例 — 就像传统 Web 应用一样。
