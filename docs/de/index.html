Kernfunktionen

Alles, was Sie für Scheduling-UIs benötigen

FlexGanttFX ist ein domänenunabhängiges Framework, das alles von der Projektplanung bis zur industriellen Einsatzplanung im Enterprise-Maßstab abbilden kann.

Hohe Performance

Canvas-basiertes Rendering mit Buffer-Architektur verarbeitet Zehntausende Aktivitäten mit 60 fps — ohne Kompromisse durch Virtualisierung.

Vollständig anpassbar

Austauschbare Renderer, CSS-Styling, ein Layer-System und eine umfassende API ermöglichen es Ihnen, jedes visuelle Detail an Ihre Domäne und Marke anzupassen.

Flexible Timeline

ChronoUnit- und SimpleUnit-Timelines unterstützen Zeiträume von Millisekunden bis Jahrzehnten mit konfigurierbaren mehrzeiligen Datelines, Gitternetzlinien und Zoomstufen.

Split-Screen-Container

Dual-, Quad- und Multi-Chart-Container mit synchronisiertem Scrollen und Zoomen für komplexe Ansichten mit mehreren Ressourcen.

Aktivitätsverknüpfungen

Modellieren und visualisieren Sie Abhängigkeiten zwischen Aktivitäten mit anpassbaren Finish-to-Start- und anderen Link-Typen, gerendert mit gebogenen oder geraden Pfeilen.

Desktop & Web

Stellen Sie dieselbe Codebasis per JavaFX auf dem Desktop, per JPro im Browser oder per GraalVM + Gluon nativ auf iOS und Android bereit.

Versionshistorie

Aktuelle Releases

FlexGanttFX wird aktiv gepflegt. Hier finden Sie die neuesten Releases. Die vollständigen Versionshinweise enthalten alle Details.

11.12.8 — Entfernen der OSGI-Bundles
17. Januar 2024
JAR-Dateien sind keine OSGI-Bundles mehr. Dadurch werden Probleme behoben, bei denen gebündelte native JavaFX-Bibliotheken mit der JavaFX-Version des Projekts kollidieren konnten.
11.12.7 — Fehlerbehebungen
2. November 2023
Behebt Probleme beim Rendering von Verknüpfungen — Verknüpfungen ohne Ziel, falsch angezeigte Verknüpfungen bei geänderter Zeilenhöhe und durch Lasso-Auswahl unterbrochene Navigation.
11.12.5 — Rendering-Korrekturen
30. März 2022
Vertikale Linienausrichtung, Skalierungsprobleme im Diagrammlayout und Regressionen beim Scrollbar-Verhalten behoben.
11.12.3 — Scrollbar-Typen
April 2021
Option für Scrollbars mit festem Zeithorizont, Umschalter zum automatischen Ausblenden und DST-Korrektur für Gitternetzlinien bei stündlicher Granularität hinzugefügt.
11.12.0 — Feinschliff
14. Mai 2020
System-Cursor, interaktive Zeilenhöhenänderung über Zeilen-Header, konsolidierte 8.x-/11.x-Lizenzschlüssel, verbesserte RadarView-Performance.
11.10.0 — Performance-Release
März 2020
Canvas-basiertes Rendering von Verknüpfungen, IntervalTree für schnellere Aktivitätssuche, Row-Canvas-Buffering — ein wichtiger Performance-Meilenstein.

FAQ

Häufig gestellte Fragen

Die häufigsten Fragen zu FlexGanttFX. Keine passende Antwort gefunden? Kontaktieren Sie uns.

Ist FlexGanttFX Open Source?
Nein, FlexGanttFX ist eine kommerzielle Software. Nach Ablauf der 30-tägigen Testphase benötigen Sie eine Entwicklerlizenz. Sobald Ihre Anwendung in Produktion geht, benötigen Sie für jede Anwendung / jedes Projekt, das Sie ausliefern möchten, eine Laufzeitlizenz.
Gibt es eine Swing-Version von FlexGanttFX?
Ja. Sie heißt FlexGantt und ist bereits seit vielen Jahren verfügbar. Sie können sie von der DLSC-Website herunterladen oder uns kontaktieren, und wir erzählen Ihnen gerne mehr darüber. Die Swing-Version funktioniert mit jeder Java-Version ab 8.
Welche Java-Versionen unterstützt FlexGanttFX?
FlexGanttFX unterstützt Java 8 bis Java 26. Die Java-8-Version verwendet das im JDK enthaltene JavaFX. Für Java 11 und höher verwenden Sie die OpenJFX-Artefakte — idealerweise die neueste verfügbare Version.
Bieten Sie Support für FlexGanttFX an?
Alle Lizenznehmer erhalten Basis-Support und Fehlerbehebungen. Optional ist ein jährlicher Wartungsplan erhältlich, der Sie für Premium-Support und kostenlose Updates qualifiziert, sobald neue Versionen verfügbar sind.
Läuft FlexGanttFX in Browsern wie Chrome oder Safari?
Ja, aber es erfordert den Einsatz von JPro. Weitere Informationen und Live-Beispiele finden Sie auf deren Website.
Welche OpenJFX-Version sollten wir verwenden?
Idealerweise verwenden Sie die neueste Version. FlexGanttFX wird kontinuierlich mit aktuellen OpenJFX-Releases getestet und funktioniert mit den Versionen 11 bis 21+.
