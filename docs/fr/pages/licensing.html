Licences

Double licence

FlexGanttFX est disponible sous deux licences : la GNU Affero General Public License v3 pour les projets open source, ou une licence commerciale pour les applications propriétaires à code fermé. Choisissez celle qui correspond à votre projet.

Licence open source (AGPLv3)

Gratuite pour les projets qui sont eux-mêmes open source. Le framework complet est inclus — aucune restriction de fonctionnalités et aucune clé de licence.

  • Gratuite — aucun frais, aucune clé de licence
  • Framework complet, sans fonctionnalités bridées
  • Votre application doit également être publiée sous licence AGPLv3
  • Le code source doit être mis à disposition de vos utilisateurs — y compris ceux qui accèdent à l’application via un réseau
Lire l’AGPLv3

Licence commerciale

Nécessaire lorsque vous ne pouvez pas ou ne souhaitez pas respecter l’AGPLv3 — par exemple pour des applications de bureau propriétaires, des logiciels internes ou une offre SaaS commerciale.

  • Utilisation dans des produits propriétaires à code fermé
  • Aucune obligation de copyleft — votre code source reste le vôtre
  • Déploiements internes, destinés aux clients et en SaaS
  • Support et corrections de bugs pour les détenteurs de licence
  • Plan de maintenance annuel avec support premium et mises à jour gratuites
Demander un devis

De quelle licence ai-je besoin ?

L’AGPLv3 suffit si…

  • votre application est open source sous licence AGPLv3
  • vous publiez l’intégralité du code source de votre application
  • vous expérimentez, évaluez ou construisez un prototype
  • vous utilisez FlexGanttFX dans l’enseignement ou la recherche, avec des résultats publiés en open source

Vous avez besoin d’une licence commerciale si…

  • votre application est propriétaire ou à code fermé
  • vous la livrez à des clients ou la déployez en interne sans publier les sources
  • vous la proposez comme service hébergé ou produit SaaS
  • la politique de votre entreprise interdit les dépendances sous licence AGPL

Aucune clé de licence requise. FlexGanttFX n’utilise plus de clés de licence ni de période d’essai. Ajoutez simplement les bibliothèques à votre projet et commencez — en utilisant FlexGanttFX, vous acceptez les conditions de la licence applicable à votre cas d’usage.

Besoin d’aide pour choisir ?

Vous ne savez pas quelle licence convient à votre projet ? Notre équipe se fera un plaisir de vous aider à trouver la meilleure option.
