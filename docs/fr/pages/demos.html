Qu’est-ce que JPro ?

La technologie derrière les démos en ligne ci-dessus : exécutez toute application JavaFX directement dans le navigateur, sans plugin ni installation.

JPro est un produit commercial développé par SANDEC GmbH qui sert de passerelle de rendu côté serveur pour les applications JavaFX. Au lieu d’exécuter l’application JavaFX sur la machine de l’utilisateur final, JPro l’exécute sur un serveur et diffuse le rendu vers tout navigateur web moderne au moyen de technologies web standard (HTML5, WebSockets et SVG/Canvas).

Du point de vue de l’utilisateur, l’application est entièrement interactive : clics de souris, saisie clavier, drag & drop et défilement fonctionnent exactement comme dans une application desktop native. Du point de vue du développeur, rien ne change non plus : vous écrivez et maintenez une seule base de code JavaFX, et JPro se charge du déploiement web.

FlexGanttFX fonctionne parfaitement avec JPro, car il s’agit d’un contrôle JavaFX pur, entièrement basé sur les API JavaFX Canvas et Scene Graph. Aucun portage ni adaptation spécifique n’est nécessaire : si cela fonctionne sur desktop, cela fonctionne dans le navigateur via JPro.

Rendu côté serveur

L’application JavaFX s’exécute sur votre serveur. JPro rend chaque frame et la diffuse au navigateur en temps réel via une connexion WebSocket.

Aucune modification du code

Votre base de code JavaFX/FlexGanttFX existante fonctionne telle quelle. JPro s’intègre comme une bibliothèque : pas de réécriture, pas de frontend web séparé à maintenir.

Tout appareil, tout navigateur

Fonctionne sur desktops, ordinateurs portables, tablettes et smartphones — Chrome, Firefox, Safari et Edge. Aucun runtime Java ni plugin requis côté client.

Les données restent sur le serveur

Comme l’application s’exécute côté serveur, les données sensibles ne quittent jamais votre infrastructure. Idéal pour les déploiements d’entreprise soumis à des exigences strictes de gouvernance des données.

Multi-utilisateur et multi-session

JPro gère plusieurs sessions utilisateur concurrentes sur le même serveur, chacune avec une instance d’application isolée — comme une application web traditionnelle.
