# Agile Sprint Planner

This demo applies **FlexGanttFX** to agile planning by visualizing stories, bugs, milestones, and related engineering work across sprint boundaries. It is intended to show how the framework can combine roadmap-style planning, layered activity types, and additional views such as burn-down or layer panels in a single cohesive application.

The sprint planning data is bundled sample data from the sprint demo module. It is deliberately composed to include different work item categories and progress states so the showcase can demonstrate how multiple activity types, links, and layouts can coexist in a planning-oriented view.
