# Space Mission Control

This demo uses a mission-control scenario to show how multiple coordinated timelines can be visualized together. Spacecraft maneuvers, contact windows, and operational activities are presented alongside related planning information, illustrating how **FlexGanttFX** can support monitoring-style applications with multiple layers and synchronized views.

The mission data is packaged with the demo itself and represents a prepared, fictional scenario rather than a live telemetry source. It is structured to exercise the dual-chart layout, side panels, and mission-specific renderers so the showcase can highlight interaction patterns as well as the visual design.
