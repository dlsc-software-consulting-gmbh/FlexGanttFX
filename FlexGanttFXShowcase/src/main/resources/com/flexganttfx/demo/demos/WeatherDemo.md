# World Climate

This demo presents a long-running climate timeline for multiple cities around the world. It highlights how **FlexGanttFX** can be used beyond classic project management by combining chart-style activities, large time ranges, and layered visual encoding such as temperature bands and precipitation intensity. Its main purpose is to demonstrate dense data visualization with a timeline-driven UI.

The weather data used here is synthetic sample data bundled with the weather module. It covers daily values across several years for a set of representative cities and climate zones, giving the demo enough variation to show seasonal patterns and rendering behavior without depending on a remote weather feed.
