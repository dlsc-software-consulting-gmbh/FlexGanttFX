# MS Project Reader

This demo shows how **FlexGanttFX** can act as a viewer for Microsoft Project plans. It focuses on reading task hierarchies, displaying dependencies, and turning imported scheduling data into a fully interactive Gantt chart with timeline navigation, tree-table details, and link rendering.

The demo starts with built-in project plans created by `SampleProjectFactory`, including the software release plan shown by default. Those projects are generated programmatically and bundled with the demo, and the view can also be used to load external `.mpp` or `.xml` files when users want to inspect their own Microsoft Project data.
