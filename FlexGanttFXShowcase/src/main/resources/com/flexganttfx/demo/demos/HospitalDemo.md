# Hospital OR Scheduler

This demo showcases an operating-room scheduling application built with **FlexGanttFX**, combining a room-focused chart, a resource-allocation chart, and a detailed day view into a single interactive planning surface. It is intended to demonstrate how the framework can handle real-world scheduling concerns such as preparation and cleanup phases, conflict detection, drag-and-resize editing, and synchronized views across multiple clinical resources.

The displayed hospital plan is generated demo data that spans a full month and stays within defined surgery hours. It is packaged with the hospital demo module so the showcase can immediately present conflict handling, resource coordination, themed styling, and custom segmented activity rendering without any external system or data import.
