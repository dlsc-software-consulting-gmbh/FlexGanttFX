# Factory Scheduling

This demo models a manufacturing-floor scheduling application with production lines, jobs, and status-driven activity rendering. It is meant to show how **FlexGanttFX** can support operational planning use cases where the focus is on machine utilization, order flow, and schedule state rather than traditional task hierarchies alone.

The displayed planning data is demo data packaged with the factory module. It is designed specifically for the demo so that different scheduling states and visual treatments are visible immediately, without requiring any database, import step, or external integration.
