# Airport Ground Operations

This demo demonstrates airport turnaround planning with aircraft movements, gate usage, and ground-operation scheduling shown in coordinated charts. Its purpose is to highlight how FlexGanttFX can model tightly timed operational workflows where several resources and activity types must stay aligned across the same planning horizon.

The displayed airport data is bundled with the airport demo and represents a prepared Frankfurt-style ground-operations scenario. It is not fetched from a live airport system; instead, it is curated to show terminal grouping, custom renderers, and synchronized chart behavior in a realistic but self-contained example.
