# Emirates Aircraft Scheduling

This demo showcases **FlexGanttFX** in a real-world airline planning scenario. It visualizes aircraft rotations, fleet assignments, and long-range scheduling windows in a dense but readable layout, with custom rendering tailored to flight operations. The main purpose is to demonstrate how the framework handles large scheduling datasets, background loading, and timeline navigation in an enterprise-style application.

The data shown in the sampler comes from bundled Emirates demo datasets exposed through the `DataSet` selector. These are packaged with the demo and loaded into a `DataModel` in the background, so users can switch between prepared scenarios without connecting to any live service or external system.
